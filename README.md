# Crime Data Analysis

## Overview
This project focuses on analyzing crime data to identify patterns, trends, and insights using data analysis and visualization techniques.

## Objectives
- Analyze crime patterns and frequency
- Identify trends based on location and crime type
- Perform data cleaning and preprocessing
- Generate insights through visualizations and dashboards

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Trend and pattern visualization
- Crime category analysis
- Insight generation using charts and graphs

## Outcome
The analysis helped in understanding crime distribution, identifying high-frequency crime categories, and visualizing trends for better interpretation of the dataset.

- `CRIME DATA ANALYSIS.ipynb`
